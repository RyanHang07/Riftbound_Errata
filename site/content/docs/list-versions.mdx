Effective dates come from Riot's patch notes. Where a page states no date, the announcement date is used and marked as such.

## As a tool

`list_versions` takes no input. It returns every version with `valid_from`, `valid_to` and `date_basis` (`announcement-date` when the patch notes state no date), or `searchable: false` with the reason.
